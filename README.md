## Über die Übungslösungen

Alle Übungslösungen in diesem Repository sind im Markdown-Format geschrieben.

Aufgrund der eingeschränkten Kompatibilität des integrierten Markdown-Renderers von GitHub werden einige Inhalte, wie z. B. erweiterte Markdown-Syntax oder mathematische Formeln, bei der direkten Ansicht auf GitHub möglicherweise nicht korrekt dargestellt.

## Empfohlene Umgebung

Für das beste Leseerlebnis wird dringend empfohlen, diese Dateien lokal mit Visual Studio Code (VS Code) und der Erweiterung *Markdown Preview Enhanced* anzusehen.

### Schritte

1. Laden Sie **Visual Studio Code** herunter und installieren Sie es.  
   https://code.visualstudio.com/

2. Öffnen Sie VS Code und installieren Sie die Erweiterung:
   - Markdown Preview Enhanced

3. Öffnen Sie eine beliebige `.md`-Datei in diesem Repository und verwenden Sie die von der Erweiterung bereitgestellte Vorschau.
